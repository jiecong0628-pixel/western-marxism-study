# 西马研习室

**西方马克思主义 · 45天理解与练习**

一个可以离线使用的西方马克思主义学习网页。面向哲学基础较弱、每天约有1小时的学生，把概念讲解、原笔记阅读、做题、订正和复习放在同一条学习路径中。

按通用复习设计，适合自学与备考；没有指定目标院校，也不预测考点或保证提分。

> 发布准备状态：仓库已更名，仍为私有；完整原笔记、三图及其历史的公开范围待确认。下列下载步骤适用于有仓库访问权限的用户，公开发布完成后才可直接分享给其他人。

## 开始使用：三步即可

1. 在仓库主页点击绿色 **Code → Download ZIP**，下载后解压整个文件夹。
2. 打开 `outputs` 文件夹，双击 **西马45天整合学习网页.html**，用浏览器阅读。网页的名字是“西马研习室”；为兼容旧入口，文件名保持原样。GitHub 上点开 HTML 只会看到源码，需要先下载。
3. 第一次打开进入 **今天学习**，确认选择的是 **第1天**，从 **旧知回忆** 开始。页面提示完成后，依次点击 **读原笔记 → 分层讲解 → 即时练习 → 书面作答 → 订正反思 → 完成记录**。

不需要安装程序、注册学习账户或运行代码。网页已嵌入学习内容；打开资料来源链接时才需要联网。手机需先下载并用能运行本地 HTML 的浏览器打开，某些文件预览器不支持交互；手机操作尚未实机验证，建议首次用电脑。

**483道自编题全部是模拟题。** 另单独收录1道从上海外国语大学2016年《马克思主义原理》原卷核验的**相关基础真题**“哲学基本问题”，不能据此推断该校西马考试范围。题目来源见网页和[来源与核查说明](outputs/西马题库来源与核查说明.md)。答案及评分点是项目自拟的教学参考，均不是院校官方答案。

选择题用于理解训练，不表示所有哲学考研科目都设置选择题。重点标签表示理论地位和教学依赖关系，不表示“必考”或院校出题频率。

## 每天怎样学

**必做：先从“今天学习”进入，按页面的60分钟预算推进。**

- 先闭书回忆，再读当天原笔记与讲解，避免一开始就看答案。
- 当天通常做2道选择题，每周检查做3道；答题前选自己的把握程度，答后阅读逐项解释与误区修正。
- 书面训练通常先写提纲，随后看完整示范，按自己真正写出的要点自评。第43、44天安排限时成文。
- 写下一处误解及自己的新解释，完成当天记录。学习日由自己推进，不会因为隔了几天没学就自动跳过。

**选做：有余力时进入“题库”。** 按章节、专题、题型、重点程度和难度筛选，再点“开始所选专题”；也可选混合练习、收藏或到期错题。题面可以展开“微课”、相关讲义和原笔记，关闭后继续作答。

不用在45天内刷完全部题。当天到期错题会按预算优先替换一题，其余留在队列。错概念在后续学习日重练，延迟答对后再安排间隔；每周根据表现调整回忆时间。选择题正确率、书面题自评分和作答信心分别记录，看到答案不等于掌握。

## 保存、备份与恢复

记录自动保存在**当前浏览器、本机的网页存储空间**，不会发送到 GitHub，也没有云同步。

- 每周、更新网页、移动文件、换浏览器或清理浏览器数据前，打开 **进度与设置 → 导出进度 JSON**，把备份存到自己能找到的文件夹。
- 下载受限时，展开 **复制备份文字／粘贴恢复**，把完整文字保存为私人文本文件。
- 在新入口打开 **进度与设置 → 从备份恢复**；也可以粘贴备份文字，检查后确认恢复。恢复会覆盖当前浏览器的学习记录，先备份当前数据。

本地 `file://` 网页的存储行为因浏览器而异；移动或改名可能产生新的存储空间。首次学习后关闭并重新打开，确认进度还在。已有用户的存储键保持不变，仍建议先导出再更新。

**不要把进度备份上传到仓库或 Issue。** 它可能包含个人解释、困惑与反思。反馈问题时使用不含真实记录的示例。

## 当前限制

- 原笔记有课堂简写与含混措辞；订正记录不等于完成了原著逐条校勘。部分手写图注不能可靠辨认，已标明。
- 未针对任何目标院校考纲调整；使用前应对照自己的参考书和考试科目。
- 大题采用自评，没有自动阅卷；正确率和自评分只能作为学习线索。
- 已检查生成一致性、题号映射及交互逻辑；真实浏览器存储、下载与文件选择、手机触摸和排版尚未实测。60分钟是任务预算，未验证每位学生均能按时完成，更未验证提分效果。
- 无账户、无跨设备自动同步；备份需要自行保存。外部来源链接需要网络，未来可能失效。

[题库验收记录](outputs/西马题库升级验收报告.md)说明检查范围；[知识点覆盖表](outputs/西马知识点与题库覆盖表.md)与[逐日计划](outputs/西马题库版45天逐日计划.md)可供核对。

## 给维护者：文件与构建

普通学习者只需打开 HTML；以下步骤仅用于修改项目。

| 文件 | 用途 |
|---|---|
| `work/app_template.html` | 网页模板、导航、每日路径与记录功能 |
| `work/question_bank/` | 可编辑的知识单元、题目和答案原稿 |
| `work/build_question_bank.py` | 题库编译及覆盖映射 |
| `work/question_bank_app.js`、`work/question_bank_style.css` | 专题练习交互与样式 |
| `work/expanded_chapters.md` 等 | 章节讲义及补充源 |
| `work/daily.tsv` | 每日原文范围与学习主题 |
| `outputs/` | 学习网页、可读整理版、题库导出、卡片与核查报告 |

修改源文件后，在仓库根目录运行：

```sh
python3 work/build_site.py
python3 work/final_qa.py
```

正常构建需要 **Python 3和Node.js**，使用标准库，不需为此安装网页框架。`work/course_data.json` 是构建生成的缓存，已忽略。只有重新从 DOCX 转录时，`work/build_source_md.py` 才需要本地原文件和 `lxml`；公开下载不含 DOCX，检查脚本会如实跳过这一对照，不影响常规网页构建。

`outputs/西马零基础图文讲义.md`、`西马互动练习.html`、`西马练习与答案.md` 是仍被构建读取的早期内容源，不是主要学习入口，不能作为临时文件删除。修改后提交相关源文件、重新生成的输出和必要说明，不能只改最终 HTML。
