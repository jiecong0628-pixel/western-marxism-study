# 西方马克思主义 45 天学习项目

这是西方马克思主义笔记的本地迭代仓库。日常学习只需打开 [45 天整合学习网页](outputs/西马45天整合学习网页.html)：从「今天学习」的第 1 天开始，依次完成回忆、原笔记阅读、讲解、练习、作答和反思。

## 文件位置

- `outputs/西马45天整合学习网页.html`：每天使用的单文件网页，原笔记文字和图片已嵌入。
- `outputs/西马原笔记完整整理.md` 与同目录的三张原图：原笔记逐段整理版。移动 MD 时请连同图片一起移动。
- `outputs/西马记忆卡片.csv`：74 张短卡，可导入 Anki。
- `outputs/西马整合网页制作清单.md`：覆盖范围、内容边界和验收记录。
- `work/`：讲义、每日安排、网页模板和生成脚本。它们是今后修改网页的源文件，不是临时缓存。
- `outputs/西马零基础图文讲义.md`、`西马互动练习.html`、`西马练习与答案.md`：生成新版网页时仍会读取的早期内容源，不作为日常学习入口。

文件夹里的原始 DOCX 保留在本机，已排除在 Git 提交之外。仓库里保存了它的完整文字整理版及三张原图。

## 用 GitHub Desktop 继续迭代

这个文件夹本身就是仓库。以后在 GitHub Desktop 里选择「西马」，便能看到每次内容或网页改动。确认改动后填写一句说明并提交，即可保留一个可回退的版本。当前仓库先保存在本机；是否发布到 GitHub 网站，可在确认隐私范围后另行决定。

## 重新生成网页（供后续编辑使用）

在仓库根目录编辑 `work/` 中相应内容后运行：

```text
python3 work/build_site.py
python3 work/final_qa.py
```

生成过程需要 Python 3 和 Node.js；只有重新从原始 DOCX 整理 MD 时才需要 `lxml`。学习网页本身无需安装这些工具，也不依赖外部脚本。网页学习进度保存在打开它的浏览器中；更新文件、换浏览器或清除数据前，先在「进度与设置」复制备份文字，之后粘贴恢复。
