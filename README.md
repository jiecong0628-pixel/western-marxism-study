# 西方马克思主义 45 天学习项目

这是西方马克思主义笔记的本地迭代仓库。日常学习只需打开 [45 天整合学习网页](outputs/西马45天整合学习网页.html)：从「今天学习」的第 1 天开始，依次完成回忆、原笔记阅读、讲解、练习、作答和反思。

## 2026-10-08 题库升级

新版网页含 **372 道选择题、111 道主观题、84 个教学知识单元**。选择题有四角度的双陈述辨析，以及36道直接四选一综合题；主观题含44道名词解释、40道简答及各9道比较、论述、材料分析。自编题全部标为模拟题；另列1道经学校原卷核验的相关基础真题，不能据此推断院校考点。

每天先从「今天学习」开始，必做2道小题（周检3道）和一项书面训练，含订正共60分钟；书面训练多数写提纲，第43/44日限时成文。额外练习从「题库」按章节、专题、题型、重点和难度选择，再点击「开始所选专题」。首次使用可选「零基础 → 主体与客体 → 选择题」。

先选择作答前的信心，再独立作答；答后查看逐项解析、补课及误区修正。题面上的「微课」「展开相关讲义」「读原笔记」可直接查看材料，关闭后作答状态保留。大题先写自己的提纲，再看参考答案，逐点自评后记录变式与反思。收藏和题目笔记保存在本机。

选择题首答正确率、大题自评分、作答信心分开记录。薄弱单元按每题最近作答更新；错概念安排次学习日再练，延迟答对后再间隔3日、7日，同日重复不晋级。按预算优先替换当天一题，其余留在队列，不要求45天刷完全部题。

旧版完成日、原答案和反思保留，新题库成绩独立记录。更新文件、换浏览器或清除数据前，请在「进度与设置」导出JSON，或复制备份文字；新入口粘贴后先检查，再确认恢复。浏览器对本地文件的保存行为可能不同，实际保存与手机显示尚未实测，详见验收报告。

## 文件位置

- `outputs/西马45天整合学习网页.html`：每天使用的单文件网页，原笔记文字和图片已嵌入。
- `outputs/西马原笔记完整整理.md` 与同目录的三张原图：原笔记逐段整理版。移动 MD 时请连同图片一起移动。
- `outputs/西马记忆卡片.csv`：74 张短卡，可导入 Anki。
- `outputs/西马整合网页制作清单.md`：覆盖范围、内容边界和验收记录。
- `work/`：讲义、每日安排、网页模板和生成脚本。它们是今后修改网页的源文件，不是临时缓存。
- `work/question_bank/`：逐单元题目、综合大题、论述答案展开、原笔记核查及旧覆盖映射的可编辑原稿。修改后重新生成，不能只改最终HTML。
- `work/build_question_bank.py`、`work/question_bank_app.js`、`work/question_bank_style.css`：分别负责题库编译、学习交互与界面样式。
- `outputs/西马专题题库数据.json`：与网页一致的完整导出，可查题号、答案、评分、来源与映射。
- `outputs/西马零基础图文讲义.md`、`西马互动练习.html`、`西马练习与答案.md`：生成新版网页时仍会读取的早期内容源，不作为日常学习入口。

文件夹里的原始 DOCX 保留在本机，已排除在 Git 提交之外。仓库里保存了它的完整文字整理版及三张原图。

## 用 GitHub Desktop 继续迭代

这个文件夹本身就是仓库。以后在 GitHub Desktop 里选择「西马」，便能看到每次内容或网页改动。确认改动后按下方提交规范填写说明并提交，即可保留一个可回退的版本。当前仓库先保存在本机；是否发布到 GitHub 网站，可在确认隐私范围后另行决定。

## Git 提交规范

本项目采用 [Git 提交规范 v1.0](docs/Git提交规范_v1.0.md)，后续协作的执行条款保存在 [AGENTS.md](AGENTS.md)。规范从采用时起生效，已有初始提交保持原样。

在 GitHub Desktop 中：

1. 在 Changes 中核对改动，仅选择本次目的涉及的文件。
2. Summary 填写 `type(scope): 中文描述`；scope 可省略，标题末尾不加句号。
3. Description 按需说明原因、影响及实际验证结果；破坏性变更按完整规范填写。
4. 再检查一次所选改动，提交到当前分支。

本项目示例（描述须与实际改动一致）：

| 改动目的 | Summary 示例 |
|---|---|
| 新增练习功能 | `feat(practice): 增加章节错题再练` |
| 修复界面缺陷 | `fix(ui): 修复手机端章节导航遮挡` |
| 补充讲义内容 | `docs(course): 补充卢卡奇物化论证步骤` |
| 更新使用说明 | `docs: 补充学习进度备份步骤` |
| 维护忽略规则 | `chore(repo): 排除本地生成的缓存文件` |

当前以文档约定执行，未启用自动拦截，也未安装提交检查工具。此规范不自动授权推送、发布或改写共享历史。

## 重新生成网页（供后续编辑使用）

在仓库根目录编辑 `work/` 中相应内容后运行：

```text
python3 work/build_site.py
python3 work/final_qa.py
```

生成过程需要 Python 3 和 Node.js；只有重新从原始 DOCX 整理 MD 时才需要 `lxml`。内容检查会对照本机DOCX（存在时），并运行题库交互逻辑检查。后者使用轻量DOM适配器，不能代替实际浏览器与手机测试。学习网页无需这些工具，无外部脚本或样式依赖；只在主动打开资料来源时需要网络。
